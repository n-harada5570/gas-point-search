ガス配送 地点コード検索アプリ（本番準備版）

【現在できること】
・iPhone向けWebアプリ
・氏名カナ部分一致検索
・全角/半角/スペース差をある程度吸収
・CSV取り込み
・UTF-8 / Shift_JIS CSVを想定
・氏名カナ列、地点コード列を自動判定
・自動判定できないCSVは画面で列を選択可能
・地点コードは文字列扱い（先頭0を保持）
・地点コード大表示
・CSV差し替え更新
・端末内保存
・PWA構成（ホーム画面追加・オフライン利用を想定）

【後から差し込むもの】
1. 実CSVの列名・文字コード・データ形状確認
2. 配送予定表バーコードの規格・中身確認
3. バーコード生成処理を barcodeMount 部分に実装

【重要】
iPhoneで完全オフライン運用するには、最初の配布時だけ
HTTPSでこの一式を公開してSafariから開き、
ホーム画面に追加する運用が安定です。
ローカルHTMLを直接開くだけではService Workerが動きません。

【想定規模】
500件程度なら検索性能上の問題はありません。
