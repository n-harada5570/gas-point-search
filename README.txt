ガス配送 地点コード検索アプリ（実データ対応版 v4）

【対応CSV】
・氏名
・氏名カナ
・配送地点バーコード
※ 顧客コードなど他の列が入っていても問題ありません。
※ UTF-8 / Shift_JIS を想定しています。

【検索】
・氏名（漢字）で検索可能
・氏名カナで検索可能
・半角/全角カナ、スペース差を正規化
・氏名カナが苗字だけでも、氏名（漢字）が入っていればフルネーム検索可能

【保存】
・CSVを取り込むと端末内 localStorage に保存
・同じ DATA_KEY（gas_customers_v2）を維持
・CSVを再取り込みすると登録データを置き換え

【バーコード】
・配送地点バーコード番号は表示/コピーまで対応
・実際のバーコード画像生成は規格確認後に barcodeMount へ実装

【更新】
・Service Worker キャッシュ v4
・オンライン時は最新版を優先、オフライン時はキャッシュを使用
