ガス配送 地点コード検索アプリ（実データ対応版 v4）

【対応CSV】
・氏名
・氏名カナ
・配送地点バーコード
※ 顧客コードなど他の列が入っていても問題ありません。
※ UTF-8 / Shift_JIS を想定しています。

【検索】
・氏名（漢字）で検索可能
・氏名カナで検索可能
・半角/全角カナ、スペース差を正規化
・氏名カナが苗字だけでも、氏名（漢字）が入っていればフルネーム検索可能

【保存】
・CSVを取り込むと端末内 localStorage に保存
・同じ DATA_KEY（gas_customers_v2）を維持
・CSVを再取り込みすると登録データを置き換え

【バーコード】
・配送地点バーコード番号は表示/コピーまで対応
・実際のバーコード画像生成は規格確認後に barcodeMount へ実装

【更新】
・Service Worker キャッシュ v4
・オンライン時は最新版を優先、オフライン時はキャッシュを使用


【v6】
・配送地点バーコード値をCode 128Bとして画面表示
・実機スキャナでの最終読取確認が必要


【v7】
・氏名/氏名カナの部分一致検索を作り直し
・半角/全角カナをNFKC正規化して同一扱い
・検索ボタン追加 + iPhoneの入力/変換確定イベントにも対応
・保存キーをv7へ分離。正常な旧データのみ自動移行
・検索結果にヒット件数を表示


【v8】
・検索データはv7をそのまま利用（再取込不要）
・バーコード描画をSVGからCanvasへ変更
・客先詳細を開くとCode 128Bを即時表示


【v9】
・バーコード描画をCanvasからSVGへ変更
・詳細画面を表示してから描画するよう修正（iPhone Safari/PWA対策）


【v10】
・実物写真3本をデコードし、規格がCODABAR（NW-7）であることを確認
・バーコードはSVGをdata URI化した画像として表示
・CSVの a...b をNW-7の A...B として符号化し、画面下の文字はCSVどおり小文字表示
